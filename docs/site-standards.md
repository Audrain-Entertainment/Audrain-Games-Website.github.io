# Site Standards

This site should feel like one cohesive experience across every page.

## Required page structure
- Every page should use the same top navigation header.
- Every page should use the same footer.
- Every page should use the same page margin and content width.
- Any page-specific action should appear in a small subheader beneath the main header, not inside the main navigation.

## Header requirements
- The logo in the upper-left should link to the home page.
- The top-right navigation should include:
  - Home
  - Android
  - Itch
  - About Me
- Use the shared stylesheet in assets/css/styles.css.

## Footer requirements
- Use the same footer content and styling on every page.
- Keep the contact links and copyright text consistent.

## Layout requirements
- Use the shared page container spacing from assets/css/styles.css.
- Keep the overall width and padding consistent so the site feels cohesive.

## When adding a new page
1. Copy the shared header structure from an existing page.
2. Add the shared footer structure.
3. Use the shared container styles.
4. If the page needs a special action link, add it as a subheader rather than changing the main header.
